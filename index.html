FAQ

Good to know

Do I need to know Java already?

Basic syntax helps, but the early days are designed for beginners. The difficulty grows gradually.

Can I use frameworks or libraries?

No. The rule is Core Java only: no Spring, JDBC, Android, GUI frameworks, APIs, databases or external libraries.

When does the next day unlock?

One new challenge opens every day, starting from the day you first log in.

Where do I write my code?

On your own computer, in any Java editor or IDE. Come back and mark the day complete when you finish.
